Level 2: 进阶优化（推荐）
DBM Loss 实现：
class DBMLoss(nn.Module):
    """难度感知平衡边际损失 - 2025最新"""
    def __init__(self, class_counts, lambda_inst=0.5):
        super().__init__()
        self.class_margin = 1.0 / torch.log1p(torch.tensor(class_counts))
        self.lambda_inst = lambda_inst
        
    def forward(self, logits, targets):
        # 1. 类别级边际
        batch_margin = self.class_margin[targets]
        
        # 2. 样本级难度（基于预测概率）
        probs = F.softmax(logits, dim=1)
        inst_difficulty = 1.0 - probs[range(len(targets)), targets]
        
        # 3. 组合边际
        combined_margin = batch_margin + self.lambda_inst * inst_difficulty
        
        # 4. 边际增强交叉熵
        logits_margin = logits.scatter(1, targets.unsqueeze(1), 
                                       logits.gather(1, targets.unsqueeze(1)) - combined_margin.unsqueeze(1))
        return F.cross_entropy(logits_margin, targets)

4.2 Macro-F1 专项优化损失
Hybrid Loss = 0.6×DBM_Loss + 0.4×Soft_F1_Loss
class SoftMacroF1Loss(nn.Module):
    """可微分Macro-F1损失，直接优化主指标"""
    def __init__(self, num_classes=8):
        super().__init__()
        self.num_classes = num_classes
        
    def forward(self, logits, targets):
        probs = F.softmax(logits, dim=1)
        targets_onehot = F.one_hot(targets, self.num_classes).float()
        
        # 逐类计算TP、FP、FN的软版本
        tp = (probs * targets_onehot).sum(dim=0)
        fp = (probs * (1 - targets_onehot)).sum(dim=0)
        fn = ((1 - probs) * targets_onehot).sum(dim=0)
        
        # 软F1计算
        precision = tp / (tp + fp + 1e-8)
        recall = tp / (tp + fn + 1e-8)
        f1 = 2 * precision * recall / (precision + recall + 1e-8)
        
        # Macro平均，最小化负F1
        return 1.0 - f1.mean()
技术来源：
- Scholz et al., "Imbalance-aware loss functions", OpenReview 2025
- Sadi et al., "LMFLOSS", arXiv:2212.12741

### 竞赛关键工程经验总结
1. **Backbone选择**：DINOv2 ViT-L/14 > EVA02 > EVA-CLIP-5B，预训练适配是必做步骤
2. **模态融合**：简单门控融合/概率融合 > 复杂交叉注意力，后者易过拟合
3. **时序处理**：后处理平滑 > 复杂时序建模，中值滤波/滑动投票性价比最高
4. **长尾处理**：Focal Loss + 类别平衡采样是标配，结合生成式增强可再+3-5%
5. **TTA配置**：8种几何变换组合，概率平均可稳定+0.8-1.2%
